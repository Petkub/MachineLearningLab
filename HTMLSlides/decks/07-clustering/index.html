Supervised vs unsupervised

SUPERVISED

You have y. Train on it. Predict on new rows.
Examples: classify Survived (deck 05/06), predict Fare (regression).

UNSUPERVISED

You only have X. No y. Find structure on your own.
Examples: group similar players (Kazakhstan TST 2025), customer segments, image compression.

Real NOAI task: cluster basketball players by stats — without knowing positions in advance. KMeans solves this.

KMeans intuition — pick k, find centers

Goal: split N points into k groups so each point is close to its group's center (centroid).

  • k = number of clusters. You pick it.
  • Each cluster has a centroid (its mean point).
  • Each point joins its nearest centroid.
  • Distance = Euclidean (straight line in feature space).
  • Final centroids reveal the structure.
3 clusters, centroids = +

Algorithm — 4 steps, repeat until stable

1. INIT
place k centroids randomly
2. ASSIGN
each point → nearest centroid
3. UPDATE
centroid = mean of its points
4. REPEAT
converged — done

Stuck local minima: bad initial centroids → bad clusters. n_init=10 retries 10 times, keeps best.

Code — fit + predict in one line

from sklearn.cluster import KMeans

km = KMeans(n_clusters=3, random_state=42, n_init=10)
labels = km.fit_predict(X)             # labels: array of cluster ids 0..k-1

km.cluster_centers_                     # the centroids (k × n_features)
km.inertia_                             # sum of squared distances to nearest centroid
paramwhat
n_clusters=khow many groups (you pick)
random_state=42seed for reproducibility
n_init=10retries to dodge bad init
max_iter=300cap on assign-update loops

Same shape as classifier API: .fit(X) + .predict(X). No y — that's the whole point.

Scaling matters — same trap as KNN

KMeans uses Euclidean distance. If Fare ranges 0-500 and Age ranges 0-80, Fare dominates. Clusters become "high-fare vs low-fare" — Age is invisible.

from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)
labels = KMeans(n_clusters=3, random_state=42, n_init=10).fit_predict(X_scaled)
  • Always scale before KMeans on real data with mixed-range features.
  • Exception: when all features are already on the same scale (pixel intensities, normalized counts).
  • After scaling, every column has mean 0, std 1. No feature dominates.

Choose k — elbow plot

Don't know how many clusters? Try several. Plot inertia (sum of squared distances) vs k. Look for the bend.

inertias = []
for k in range(1, 9):
    km = KMeans(n_clusters=k,
                random_state=42,
                n_init=10).fit(X_scaled)
    inertias.append(km.inertia_)

plt.plot(range(1, 9), inertias, 'o-')
plt.xlabel('k'); plt.ylabel('inertia')
plt.show()
  • Trap: inertia ALWAYS decreases as k grows. Maximum k always "wins" — useless.
  • Pick the bend — where extra k stops helping much.
elbow plot — bend at k=3

Choose k — silhouette score (numeric)

Higher silhouette = clusters are tight inside AND far apart. Pick k with the highest score.

from sklearn.metrics import silhouette_score

sils = []
for k in range(2, 9):
    km = KMeans(n_clusters=k,
                random_state=42, n_init=10).fit(X_scaled)
    sils.append(silhouette_score(X_scaled, km.labels_))

best_k = 2 + np.argmax(sils)
  • Range: [-1, 1]. Higher = cleaner separation.
  • Silhouette won't compute for k=1. Start at 2.
  • Use silhouette + elbow together — they should agree.
silhouette peaks at k=3

PCA — project to 2D so you can plot

Iris has 4 features. Titanic has 6+. Can't plot 4D. PCA finds the 2 directions where data spreads most, projects everything onto them.

from sklearn.decomposition import PCA

pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)    # shape: (n_rows, 2)

plt.scatter(X_pca[:, 0], X_pca[:, 1], c=labels, cmap='viridis')
plt.xlabel('PC 1'); plt.ylabel('PC 2')
plt.show()
  • PC 1 = direction of maximum variance.
  • PC 2 = next direction, perpendicular to PC 1.
  • Color by cluster label $\Rightarrow$ visual sanity check.
  • pca.explained_variance_ratio_ tells how much info each PC captures.

Use PCA to visualize, not as your main feature reduction. KMeans + PCA is the classic visualization combo.

Sanity check — vs hidden truth

If you secretly have labels (like iris species), check whether clusters match. Cluster ids are arbitrary — cluster 0 isn't necessarily species 0. Use a crosstab.

ct = pd.crosstab(y_true, labels)
purity = ct.max(axis=1).sum() / len(y_true)

purity = (50 + 39 + 36) / 150 = 0.83

  • Each row should be dominated by ONE column.
  • Purity > 0.7 = clustering recovered structure well.
  • In real NOAI tasks you don't have y — sanity check only works in toy / validation data.

Pitfalls

mistakesymptom / fix
cluster on un-scaled featuresone big-range feature dominates. StandardScaler.fit_transform(X) first.
pick k from inertia aloneinertia always falls — biggest k always "wins." Use silhouette OR look for the bend.
missing n_initrandom seed bad → stuck local minimum. Always n_init=10.
missing random_statedifferent clusters every run. Set random_state=42.
KMeans on non-globular shapesmoons, rings, irregular blobs → KMeans fails. Try DBSCAN or spectral clustering.
compare cluster ids to ground truth directlycluster 0 ≠ species 0. Use pd.crosstab, not (labels == y_true).mean().
