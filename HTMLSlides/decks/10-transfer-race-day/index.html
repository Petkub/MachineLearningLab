  • Early layers — simple features (edges, colors). Generic.
  • Middle layers — combinations (shapes, textures). Less generic.
  • Late layers + FC head — task-specific (cat vs dog).

Insight: early/middle layers learn things that transfer across tasks. Don't retrain them.

Why pretrained wins

  • ResNet18 trained on ImageNet = 1.2M images, 1000 classes, weeks of GPU time.
  • It already knows what edges, eyes, wheels, fur, metal look like.
  • Your task: 500 flower images. Train from scratch $\Rightarrow$ overfit, garbage.
  • Smart move: replace just the last layer. Let it adapt to your classes.
Story: ResNet learned to see edges by looking at 1.2M cats, dogs, planes. When you give it flowers, it doesn't need to relearn what an edge is. It only needs to learn which combinations of edges = which flower.

Rule: 95% of NOAI image tasks → start with pretrained=True. Never train from scratch on small data.

3 transfer learning modes

1. FROZEN BASE

Freeze ALL pretrained layers. Train only new head.
+ fastest, ~5 min
− least flexibility
Use when: ≤ 1k images, similar domain (animals → flowers)

2. PARTIAL FT

Freeze early layers. Fine-tune last few + head.
+ middle ground
− more careful tuning needed
Use when: 1k–10k images, somewhat different domain

3. FULL FT

Unfreeze everything. Train all layers (small lr).
+ most flexibility
− slow, easy to wreck pretrained weights
Use when: ≥ 10k images, different domain (X-rays, satellite)

For NOAI: almost always mode 1 or 2. Race day = no time to tune mode 3.

Template part 1 — load pretrained

import torch
import torch.nn as nn
from torchvision import models

# 1. load pretrained model
model = models.resnet18(pretrained=True)
# downloads ImageNet weights (~45 MB) on first run
# in newer torchvision: weights=models.ResNet18_Weights.DEFAULT
  • torchvision.models ships dozens of architectures with pretrained weights.
  • Other options: resnet50, efficientnet_b0, mobilenet_v3_small.
  • Trap: forget pretrained=True $\Rightarrow$ random weights. Trains forever, never converges.

Camp tip: ResNet18 is the survival default. Small enough to fit, big enough to win baselines.

Template part 2 — freeze the base

# 2. freeze all parameters
for param in model.parameters():
    param.requires_grad = False

# after this, NO gradients flow through any layer
# model is now read-only

What just happened:

  • requires_grad = False on every weight $\Rightarrow$ no gradient, no update.
  • Forward pass still runs (predictions work). Backward simply skips them.
  • Saves memory (no gradient buffers) and time (no backprop math).

Why this works: pretrained features are already good. We just add a small task-specific layer on top.

Template part 3 — swap the head

# 3. replace the final classification layer
NUM_CLASSES = 10   # your dataset's number of classes

# ResNet's last layer is named 'fc'
model.fc = nn.Linear(model.fc.in_features, NUM_CLASSES)
# in_features = 512 for ResNet18, automatic

# the new head has requires_grad=True by default
# it's the only thing that will train
  • model.fc.in_features — read it from the model, don't hardcode.
  • Different architecture, different name: model.classifier (DenseNet, EfficientNet), model.heads (ViT).
  • Trap: replacing model.fc AFTER the freeze loop $\Rightarrow$ new layer is trainable. Order matters.

Template part 4 — train only the head

# 4. move to GPU + training setup
device = 'cuda' if torch.cuda.is_available() else 'cpu'
model = model.to(device)

criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.fc.parameters(), lr=0.001)
# ↑ pass model.fc.parameters() — NOT model.parameters()

# 5. standard training loop (only the head trains)
for epoch in range(3):
    for x, y in train_loader:
        x, y = x.to(device), y.to(device)
        optimizer.zero_grad()
        output = model(x)
        loss = criterion(output, y)
        loss.backward()
        optimizer.step()
  • Pass model.fc.parameters() — not full model.parameters(). Optimizer ignores frozen layers anyway, but cleaner this way.
  • 3 epochs usually enough for frozen-base mode. Head converges fast.
  • Same 5-line loop as deck 09. Recognize the shape.

Image DataLoader — feed pretrained model

from torchvision import transforms, datasets
from torch.utils.data import DataLoader

transform = transforms.Compose([
    transforms.Resize((224, 224)),         # ResNet expects 224x224
    transforms.ToTensor(),                  # PIL → tensor (0..1)
    transforms.Normalize(
        mean=[0.485, 0.456, 0.406],     # ImageNet stats
        std =[0.229, 0.224, 0.225],
    ),
])

train_ds = datasets.ImageFolder('data/train', transform=transform)
train_loader = DataLoader(train_ds, batch_size=32, shuffle=True)
  • CRITICAL: use ImageNet's mean/std for any ImageNet-pretrained model. Same numbers, copy-paste.
  • Resize to 224x224 for ResNet/ViT/most ImageNet models. EfficientNet may want different.
  • ImageFolder auto-reads data/train/<class_name>/img.jpg structure.

Full template — print + memorize

import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import models, transforms, datasets
from torch.utils.data import DataLoader

# 1. data
transform = transforms.Compose([
    transforms.Resize((224, 224)), transforms.ToTensor(),
    transforms.Normalize([0.485,0.456,0.406], [0.229,0.224,0.225]),
])
train_loader = DataLoader(datasets.ImageFolder('data/train', transform=transform), batch_size=32, shuffle=True)

# 2. model — load + freeze + new head
model = models.resnet18(pretrained=True)
for p in model.parameters(): p.requires_grad = False
NUM_CLASSES = 10
model.fc = nn.Linear(model.fc.in_features, NUM_CLASSES)

# 3. train
device = 'cuda' if torch.cuda.is_available() else 'cpu'
model = model.to(device)
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.fc.parameters(), lr=1e-3)

for epoch in range(3):
    for x, y in train_loader:
        x, y = x.to(device), y.to(device)
        optimizer.zero_grad()
        loss = criterion(model(x), y)
        loss.backward()
        optimizer.step()

~25 lines. Wins most camp image baselines. Copy, change NUM_CLASSES, run.

Race Day — Phase 1: read, don't code

PHASE 1
first 15 min — DO NOT TOUCH KEYBOARD

Understand the task before you code anything

  • Read the task description completely. Twice.
  • Identify the scoring metric: accuracy? F1? IoU? RMSE? mAP?
  • Look at the sample submission file. What format? CSV? JSON? What columns?
  • Open the baseline notebook if provided. What does it do? What model? What data?
  • Check the dataset: train.csv, test.csv, image folders? Sizes?

Mistake: students start coding immediately, write the wrong metric, submit garbage for hours. 15 min reading saves 4 hours.

Race Day — Phase 2: get a working pipeline

PHASE 2
next 45 min — get any score on the leaderboard

Run baseline → submit → confirm scoring works

  • Run the baseline as-is. Don't change anything yet.
  • Produce the submission file. Confirm format matches sample.
  • Submit. Confirm it's accepted. Get a score.
  • Goal: non-zero score on leaderboard within first hour.

Why this matters: a working pipeline beats a fancy idea. With pipeline working, you can iterate fast. Without pipeline, you can't iterate at all.

Race Day — Phase 3: improve incrementally

PHASE 3
remaining time — climb the leaderboard

Change ONE thing. Submit. Note direction.

  • Try different model: LogisticRegression → RandomForest, resnet18 → resnet50.
  • Add or remove ONE feature. Re-train. Submit.
  • Increase epochs (only if loss still falling).
  • Adjust learning rate (lower if unstable, higher if too slow).
  • Track every submission: what changed, what score moved.

Trap: change 5 things, score drops, no idea which one broke it. One thing at a time.

Race Day — Phase 4: when stuck

PHASE 4
when nothing works — recovery protocol

Diagnose, don't panic

  • Read the last line of the error message, not the first. That's the actual problem.
  • Print df.head(), tensor.shape, len(dataset) at every step. Verify each.
  • If model isn't learning: lower lr by 10×, simplify model, smaller batch.
  • If cuda out of memory: shrink batch size, use resnet18 not resnet50.
  • Forget zero_grad? See deck 09.
  • Asking mentors is allowed and expected. Don't waste 2 hours on something they fix in 30 sec.

Don'ts + resources

✗Don't train from scratch when pretrained is available.
✗Don't write "clean" code first. Make it work, clean later.
✗Don't run 100 epochs on first try. Try 2-3.
✗Don't change multiple things between submissions.
