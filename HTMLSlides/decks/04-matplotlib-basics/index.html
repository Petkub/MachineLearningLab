7 plots. Each one job.
See data before you train it.

Petkub :D

Why plot?

  • You loaded a CSV. df.describe() gave numbers. Numbers lie.
  • Mean=50, std=10 $\Rightarrow$ could be bell, two clumps, or one outlier.
  • Eyeball distribution, relationship, imbalance $\Rightarrow$ catch bugs in 5 sec.

Matplotlib ships 100s of plot types. Master 7 — survive every camp task.

Setup — one import, one rule

import matplotlib.pyplot as plt

plt.hist(df['Age'])
plt.show()       # ALWAYS — or no window appears
  • Convention: import matplotlib.pyplot as plt. Always plt.
  • Rule: end every plot with plt.show().
  • In Jupyter notebook: plt.show() often optional. In .py file: required.

Skip styling, skip subplots, skip seaborn. 4 plots is enough.

# sort + horizontal — long category names

df['Pclass'].value_counts(normalize=True)

Critical: plot the target column first. 95/5 split = "always predict majority" hits 95% accuracy and learns nothing.

4. plt.boxplot — quartiles & outliers

plt.boxplot(df['Age'].dropna())
plt.show()

# compare distribution per group
df.boxplot(column='Age', by='Pclass')
plt.show()
  • Box = middle 50% (Q1–Q3, IQR).
  • Red line = median (Q2).
  • Whiskers ≈ 1.5 × IQR from box.
  • Dots beyond whiskers = outliers.
  • Compare classes side-by-side $\Rightarrow$ catches "Class 1 is older" in 1 sec.
Age distribution per Pclass — Class 1 older

5. plt.plot — line / training curves

# critical for Day 3 PyTorch training
epochs = range(1, num_epochs+1)
plt.plot(epochs, train_losses, label='train')
plt.plot(epochs, val_losses,   label='val')
plt.xlabel('epoch'); plt.ylabel('loss')
plt.legend()
plt.show()
  • train ↓ & val ↓ — learning fine.
  • train ↓ & val ↑ — overfitting. Stop early.
  • both flat — bug or LR too small.
  • both nan — LR too big or no zero_grad.
  • Always log losses each epoch. Plot every run.
Loss per epoch — val rising = overfit at ~ep 5

7. plt.subplots — many plots, one figure

fig, axes = plt.subplots(2, 2, figsize=(10,8))

axes[0,0].hist(df['Age'])
axes[0,0].set_title('Age')

axes[0,1].hist(df['Fare'])
axes[0,1].set_title('Fare')

axes[1,0].scatter(df['Age'], df['Fare'])
axes[1,1].boxplot(df['Fare'].dropna())

plt.tight_layout()
plt.show()
  • Returns fig + 2D array of Axes objects.
  • Call methods on axes[i,j], not plt.
  • tight_layout() $\Rightarrow$ no overlapping titles.
  • Camp baseline notebooks use this everywhere — recognize it.
[0,0] hist Age
[0,1] hist Fare
[1,0] scatter
[1,1] boxplot
2×2 grid — Titanic diagnostics in one figure

Always-add decorations

plt.xlabel('Age'); plt.ylabel('Count')
plt.title('Titanic — age distribution')
plt.legend()                      # after using label= in plot calls
plt.grid(True, alpha=0.3)        # light grid
plt.xlim(0, 80); plt.ylim(0, 150)  # clip axes
plt.xticks(rotation=45)            # long category names
plt.figure(figsize=(10,6))           # bigger figure — call BEFORE plot
plt.savefig('out.png', dpi=150)    # save instead of show
  • Order matters: figure → plot → labels → show/savefig.
  • savefig before show — show() closes the figure on some backends.

Common pitfalls

symptomcause / fix
blank window or no plotmissing plt.show() in a .py script
plots stack into one figureprevious figure not closed — call plt.figure() first or plt.close() between
imshow shows weird colorsRGB shape (H,W,3) with cmap='gray' $\Rightarrow$ drop cmap
imshow looks black/white onlyvalues not in [0,1] or [0,255] $\Rightarrow$ check image.min(), image.max()
scatter is one black blob10k+ points overplot $\Rightarrow$ alpha=0.1 or plt.hexbin
hist y-axis useless (one tall bar)outlier dominates $\Rightarrow$ range=(...) or log=True
legend missing / emptyforgot label= in plot() calls
savefig produced empty PNGcalled plt.show() first $\Rightarrow$ savefig before show
x-tick labels overlapplt.xticks(rotation=45) or tight_layout()
