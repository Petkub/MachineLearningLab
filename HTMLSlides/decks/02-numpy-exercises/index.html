Exercise 01 vectorize warm-up

Squares, then filter, then sum

Build 1..10. Compute three things in order, each using the previous.

Think first Three independent ops chain naturally: build → square → mask → reduce. Each step is one line. The question forces you to name intermediates so you can reuse them.
  1. Make a = [1, 2, ..., 10] as a NumPy array.
  2. Compute sq = each element squared.
  3. From sq, keep only the squares of odd originals, then sum them. Call it odd_sq_sum.
Hint. np.arange(1, 11). a ** 2. Mask odd: a % 2 == 1 — apply it to sq, then .sum().
Solution. 
a  = np.arange(1, 11)
sq = a ** 2
odd_sq_sum = sq[a % 2 == 1].sum()

Evens: count, sum, fraction

From a = [3, 8, 5, 2, 7, 6, 4, 1]:

  2. n_even = number of evens. sum_even = sum of even values.

Exercise 03 argmin think

Closest — and the runner-up

a = [10, 25, 33, 50, 71], target = 30.

Think first Distances are computed once; both closest and runner-up come from sorting by them. argsort gives positions in ascending order — first = closest, second = runner-up. Index those back into the original to get values.
  1. d = absolute distance from each element to target.
  2. closest_val and closest_dist using argmin.
  3. runner_up = second-closest value. (Hint: sort by d.)
Hint. d = np.abs(a - target). i = d.argmin() ⇒ a[i], d[i]. order = np.argsort(d) ⇒ a[order[1]] = runner-up.
Solution. 
d = np.abs(a - target)
i = d.argmin()
closest_val  = a[i]
closest_dist = d[i]
order = np.argsort(d)
runner_up = a[order[1]]

Exercise 05 copy / view think

Swap rows, then swap cols

m = np.arange(9).reshape(3, 3). Build a new matrix with row 0↔2 and col 0↔2 swapped.

Think first Two independent reorderings — apply them sequentially, or compose them in one line. m[[2,1,0]] reorders rows. Then [:, [2,1,0]] reorders cols. .copy() in step 3 protects the original from later mutation.
  1. m_rows = m with rows 0 and 2 swapped (use a row-index list).
  2. m_swap = also swap columns 0 and 2 of m_rows.
  3. Verify: m still equals np.arange(9).reshape(3,3) (we didn’t mutate it).
Hint. Fancy index makes new arrays. m[[2,1,0]] is safe. (m == np.arange(9).reshape(3,3)).all() checks equality.
Solution. 
m_rows = m[[2, 1, 0]]
m_swap = m_rows[:, [2, 1, 0]]
ok = (m == np.arange(9).reshape(3,3)).all()

Exercise 06 slice maths think

Border, inside, corners

m = np.arange(25).reshape(5, 5).

Think first Three regions partition the matrix: corners (4 cells) ⊂ border (16 cells) ⊂ all (25 cells). Every region has a clean expression. Border = total − inside avoids double-counting corners.
  1. inside = the 3×3 inner block. inside_sum = its sum.
  2. border_sum = total of m minus inside_sum.
  3. corner_sum = sum of the 4 corner values via fancy indexing.
Hint. inside = m[1:-1, 1:-1]. Corners → rows [0,0,-1,-1], cols [0,-1,0,-1]: m[[0,0,-1,-1], [0,-1,0,-1]].sum().
Solution. 
inside     = m[1:-1, 1:-1]
inside_sum = inside.sum()
border_sum = m.sum() - inside_sum
corner_sum = m[[0,0,-1,-1],
               [0,-1,0,-1]].sum()

Exercise 07 broadcast think

Normalize, clip, count

a = [10, 20, 30, 40, 50].

Think first Normalize to [0,1] is two-step: shift so min→0, scale so max→1. Once normalized, threshold logic is just a mask. Clipping is symmetric to ReLU but bounded both sides.
  1. n = a rescaled into [0, 1] (min→0, max→1).
  2. n_clip = clip n into [0.2, 0.8].
  3. n_high = how many elements of n are ≥ 0.5.
Hint. n = (a - a.min()) / (a.max() - a.min()). np.clip(n, 0.2, 0.8). (n >= 0.5).sum().
Solution. 
n      = (a - a.min()) / (a.max() - a.min())
n_clip = np.clip(n, 0.2, 0.8)
n_high = (n >= 0.5).sum()

Exercise 09 where tricky

ReLU, count zeroed, leaky variant

x = [-3, 2, -1, 0, 5, -7, 4].

Think first ReLU = pick max with 0. Count zeroed = count negatives in original. Leaky ReLU keeps a small slope for negatives — the structure is same condition, different replacement: where(x > 0, x, 0.1 * x).
  1. y = ReLU of x (negatives → 0).
  2. n_zeroed = number of elements that became 0 due to ReLU.
  3. y_leaky = leaky ReLU with slope 0.1 for negatives.
Hint. np.maximum(x, 0). Count zeroed = count where x < 0. np.where(x > 0, x, 0.1 * x).
Solution. 
y        = np.maximum(x, 0)
n_zeroed = (x < 0).sum()
y_leaky  = np.where(x > 0, x, 0.1 * x)

Exercise 10 shift tricky

Centered grid → distance → squared

For N = 7, build a centered grid, then compute distance arrays.

Think first Center via shift: arange(N) - N // 2. Once centered, distance from origin is just abs(g). Squared distance is g ** 2. Symmetric ⇒ g.sum() is 0 (sanity check).

  2. d_abs = absolute distance from 0 at each position.
  3. d_sq = squared distance. Verify g.sum() == 0.
Hint. g = np.arange(7) - 7 // 2. np.abs(g). g ** 2. g.sum() == 0 ⇒ True.

Recap — what you trained

  • Chain operations — name intermediates, reuse them. Each line one idea.
  • Mask once, use thrice — bool array works for count, filter, and fraction.
  • argmin / argmax / argsort — get position, look up value, index back.
  • Slice arithmetic — n // 2, 1:-1, ::-1. Generalize, don’t hard-code.
  • Total − part — easier than handling overlaps directly.
  • Axis reductions stack — row-sum then mask then count.
  • where vs maximum — same shape, picks element-wise from two choices.
  • Shift to center — arange(N) − N // 2 is the universal trick.

10 problems × 3 sub-tasks = 30 micro-decisions, zero for. Now you build, not loop.
