Day 2 camp shape

  • Tabular CSV with strings + numbers + NaN.
  • Encode strings $\to$ numbers. Fill NaN.
  • Engineer derived features (more signal per row).
  • Scale if model needs distance.
  • Train + score 4 models. Pick winner.

Same shape every camp tabular task. Memorize the order.

1. Encode — strings → numbers

Models eat numbers only. Strings cause ValueError: could not convert string to float.

# 2 known values — explicit map
df['Sex'] = df['Sex'].map({'male': 0, 'female': 1})

# many values — factorize
df['Embarked'] = pd.factorize(df['Embarked'])[0]
# 'S' → 0, 'C' → 1, 'Q' → 2

# one-hot — when categories have NO order
df = pd.get_dummies(df, columns=['Embarked'])
# adds Embarked_S, Embarked_C, Embarked_Q (0/1 each)

picking encoder

data shapeencoder

Trap: factorize gives integer codes. Tree models OK. Linear models may misread "3 > 2 > 1" as ordering.

2. Impute — patch NaN

Different columns need different fills. Pick by data shape, not habit.

column typestrategywhy
numeric, bell-shaped (Age).fillna(.mean())mean = center
numeric, heavy-tailed (Fare).fillna(.median())outliers drag mean wrong
categorical (Embarked).fillna(.mode()[0])"most common" makes sense
too many NaN (>50%)df.drop('col', axis=1)not enough signal — drop column

Always impute BEFORE encode/scale. Otherwise NaN survives into the model.

3. Feature engineering — derive signal

Combine existing columns into ones the model finds easier to use.

df['FamilySize']    = df['SibSp'] + df['Parch'] + 1
df['IsAlone']       = (df['FamilySize'] == 1).astype(int)
df['FarePerPerson'] = df['Fare'] / df['FamilySize']
df['AgeGroup']      = pd.cut(df['Age'], bins=[0,12,18,60,100], labels=['child','teen','adult','senior'])
  • Combine 2 cols into 1 (FamilySize).
  • Threshold a numeric to a flag (IsAlone).
  • Ratio two cols (FarePerPerson — captures wealth-per-person).
  • Bin a numeric into ranges (AgeGroup).

Good feature = pattern that's easier for the model to use than the raw inputs. Brainstorm 3-5 per task.

4. Scale — equal footing for distance models

KNN measures Euclidean distance. Fare ranges 0-500, Sex is 0-1. Fare dominates. Scale fixes it.

from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X_train)
# every column now has mean=0, std=1
modelneeds scale?
KNeighbors, SVMYES — distance based
LogisticRegressionrecommended — helps converge
RandomForest, GradientBoostNO — split on thresholds, scale invariant
Neural netsYES — gradients explode otherwise

Trap: never fit the scaler on test data. Fit on train only. Apply to both.

5. Pipeline — chain steps, no leak

Pipeline binds preprocessing + model. One .fit() trains everything correctly.

from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier

pipe = Pipeline([
    ('scaler', StandardScaler()),
    ('knn',    KNeighborsClassifier(n_neighbors=5)),
])

pipe.fit(X_train, y_train)         # scaler fits on train, then knn fits on scaled train
preds = pipe.predict(X_test)        # scaler transforms test (NOT refit), knn predicts

  • No leak: scaler never sees test data during fit.
  • One unit: pipe.predict auto-applies scaler before model.
  • Camp baselines look like this. Recognize on sight.

8. Cross-validation — single split lies

Lucky split → score too high. Unlucky split → score too low. CV averages 5 folds for honest score.

from sklearn.model_selection import cross_val_score

scores = cross_val_score(rf, X, y, cv=5)
print(f'{scores.mean():.3f} ± {scores.std():.3f}')

5 folds — each row gets used as test exactly once. Red = test fold for that round.

Pitfalls

mistakesymptom / fix
target column inside Xdata leak — score 99% on test, fails real-world. X = df.drop('target', axis=1)
fit scaler on full data (X), then splittest info leaked through scaler stats. Always split FIRST, scale on train only.
forgot to encode stringsValueError: could not convert string to float. map / factorize / get_dummies first.
KNN/SVM without scalinglarge-range features dominate. Wrap in Pipeline with StandardScaler.
imbalanced data, only check accuracy"always predict majority" hits 95%. Check F1, recall, ROC-AUC.
random_state missingdifferent score every run. Set random_state=42 on split AND model.
only test on one splitcan be lucky/unlucky. Use cross_val_score(cv=5) for honest estimate.
