Problem 01 inspect warm-up

What's in this DataFrame?

You loaded df = pd.read_csv('train.csv'). Mentor asks 3 quick facts.

  2. How many columns? Save in n_cols.
  3. Which columns hold numeric data? Save the list of names in numeric_cols.

Problem 02 slice warm-up

Pull out the rows that match

From the same DataFrame: who's a child and in third class?

Think first Two conditions. Both must hold. The trap: Python's and doesn't work on Series — pandas needs the bitwise operator and parentheses around each clause.
  1. Build a boolean mask: Age < 12 AND Pclass == 3. Save as mask.
  2. Use mask to extract those rows into a new DataFrame kids3.
  3. From kids3, get only the Name and Age columns. Call it kids3_short.
Hint. Use &, not and. Wrap each clause: (df['Age'] < 12) & (df['Pclass'] == 3). Subset columns: kids3[['Name','Age']].
Solution. 
mask = (df['Age'] < 12) & (df['Pclass'] == 3)
kids3 = df[mask]
kids3_short = kids3[['Name', 'Age']]

Problem 03 repair warm-up

Patch holes — without breaking the rest

Column Age has 177 NaN out of 891. Don't drop the rows — keep them, but fill missing.

Think first Two questions: which value to fill with, and which column to write to. Filling Age with the mean of Age is the survival default for numeric. The trick: assign back to the same column.
  1. How many rows have a missing Age? Save as n_missing.
  2. Compute the average Age over rows that aren't missing. Save as avg_age.
  3. Fill missing Age with avg_age. After this, df['Age'].isnull().sum() must equal 0.
Hint. df['Age'].isnull().sum() counts NaN. df['Age'].mean() already skips NaN. Then assign: df['Age'] = df['Age'].fillna(avg_age).
Solution. 
n_missing = df['Age'].isnull().sum()
avg_age   = df['Age'].mean()
df['Age'] = df['Age'].fillna(avg_age)

Problem 04 summarize think

Did class matter for survival?

Compute survival rate per Pclass. Then identify the safest class.

Think first "Per X" almost always means group-by. The metric is mean of a 0/1 column, which equals the rate. Don't loop over classes — let pandas split them for you.
  1. Compute survival rate for each Pclass. Save as Series rate.
  2. Which Pclass has the highest rate? Save the class number as safest_class.
  3. How big is the gap between safest and least safe? Save as gap.
Hint. df.groupby(KEY)[METRIC].mean(). Then rate.idxmax() for the winning key. rate.max() - rate.min() for spread.
Solution. 
rate = df.groupby('Pclass')['Survived'].mean()
safest_class = rate.idxmax()
gap = rate.max() - rate.min()

Problem 05 combine think

Family size, then count the lonely ones

Each row has SibSp (siblings/spouses) and Parch (parents/children). Build a "family size" feature and use it.

Think first Two columns combine into a third — vectorized add. Don't forget self if family size means "people in the row's group". Then a count question + a derived label.
  1. Add column FamilySize = SibSp + Parch + 1 (counting the passenger themselves).
  2. Add column IsAlone = True when FamilySize == 1, else False.
  3. How many passengers are alone? Save as n_alone. What fraction? Save as frac_alone.
Hint. df['FamilySize'] = df['SibSp'] + df['Parch'] + 1. df['IsAlone'] = df['FamilySize'] == 1. df['IsAlone'].sum() counts True. Divide by len(df).
Solution. 
df['FamilySize'] = df['SibSp'] + df['Parch'] + 1
df['IsAlone']    = df['FamilySize'] == 1
n_alone    = df['IsAlone'].sum()
frac_alone = n_alone / len(df)

Problem 06 compose tricky

Filter, then split, then compare

Among adults (Age ≥ 18), did women in lower classes pay less than women in 1st class?

Think first Three operations chain: filter once for "adult women", group by Pclass, take mean of Fare. Each step shrinks the data. The bug to avoid: applying filter inside the groupby instead of before — keep stages separate.
  1. Build aw — adult women only (Age >= 18 AND Sex == 'female').
  2. From aw, get average Fare per Pclass. Save Series fare_by_class.
  3. Compute fare_gap = fare_by_class for Pclass 1 minus the mean fare across Pclass 2 and 3.
Hint. (df['Age']>=18) & (df['Sex']=='female'). Then aw.groupby('Pclass')['Fare'].mean(). Index in: fare_by_class.loc[1] and fare_by_class.loc[[2,3]].mean().
Solution. 
aw = df[(df['Age'] >= 18) & (df['Sex'] == 'female')]
fare_by_class = aw.groupby('Pclass')['Fare'].mean()
fare_gap = fare_by_class.loc[1] - fare_by_class.loc[[2, 3]].mean()
