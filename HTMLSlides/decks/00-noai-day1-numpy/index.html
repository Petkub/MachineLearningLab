Warm-up — Python list vs array

Plain Python: [1,2,3] * 2 → ?   NumPy: np.array([1,2,3]) * 2 → ?   Predict both, then explain the difference in one sentence.
ANSWER
[1,2,3] * 2                  # [1, 2, 3, 1, 2, 3]   (repeat)
np.array([1,2,3]) * 2        # [2, 4, 6]            (element-wise)
Critical: Same syntax, different meaning. Python list = container of objects. NumPy array = math object. The whole point of switching libs.

Why arrays?

  • 1,000,000 numbers. Multiply each by 2.
  • Python list + for loop $\Rightarrow$ slow. Seconds.
  • NumPy: a * 2. One line. ~50× faster.
  • Same idea powers GPU neural net training.

Loops expensive. Arrays cheap. Think in arrays.

What is NumPy?

  • N-dimensional array library for Python.
  • Foundation under pandas, scikit-learn, PyTorch, TensorFlow.
  • Written in C → fast loops without writing C.

Make arrays without typing them

  • random.rand / randn — quick test data.

Even-indexed students

Class has 10 students. scores = np.arange(10) * 10 + 50 (50, 60, …, 140). Get scores at even indices only. Then get the last 3 students. Then both at once.
Think: Which slice gets every other element? Why does scores[-3:] beat scores[7:10] when class size might change?

Celsius → Fahrenheit, no loop

You have a week of temperatures in Celsius. Convert all to Fahrenheit. Then find which days were above 30°C. Solve without a single for loop.

Normalize each column

Dataset has 5 students × 3 subjects. Subtract each subject's mean from every student's score, so every column has mean 0. Will data - data.mean() work? Why not?
GIVEN
data = np.array([[80, 70, 60], [85, 65, 75], [90, 80, 70], [60, 75, 85], [70, 90, 80]])
Think: data.mean() = scalar. data.mean(axis=0) = shape (3,). Which one broadcasts the way you want? What shape result do you need?
SOLUTION
col_means = data.mean(axis=0)   # shape (3,) — one per subject
centered  = data - col_means     # broadcasts down rows

centered.mean(axis=0)            # ≈ [0, 0, 0] ✓
Twist: Now normalize each row instead (per-student mean). Why does data - data.mean(axis=1) fail, and how do you fix it with [:, None]?

Best student, best subject

Same 5 × 3 score matrix. Find: (1) class average per subject, (2) total score per student, (3) which student got the highest total, (4) which subject the class did worst in.
Think: Axis = the dimension that disappears. Per-subject collapses rows → axis=0. Per-student collapses cols → axis=1. Sketch it on paper if stuck.
SOLUTION
subj_mean   = data.mean(axis=0)    # shape (3,) — per subject
stud_total  = data.sum(axis=1)     # shape (5,) — per student

best_stud   = stud_total.argmax()    # index of top student
worst_subj  = subj_mean.argmin()     # index of worst subject

Find the outliers

Lab measured 20 sensor readings. Anything more than 2 standard deviations from the mean is suspect. Find: how many outliers, their indices, and replace them with the median.
GIVEN
rng = np.random.default_rng(0); x = rng.normal(50, 5, size=20); x[3] = 90; x[15] = 10
Think: Mask = boolean array. mask.sum() counts True. np.where(mask) gives indices. x[mask] = value assigns in place.
SOLUTION
mean, std = x.mean(), x.std()
mask = np.abs(x - mean) > 2 * std

n_out   = mask.sum()
idx_out = np.where(mask)[0]
x[mask] = np.median(x)            # replace in place
Critical: Why use median not mean for replacement? (Outliers pull mean. Median is robust.)

Build the feature matrix

3 separate feature arrays (age, height, weight), each length 100, plus labels y. Build matrix X of shape (100, 3), then split the first 80 rows as train, last 20 as test. No loop.
GIVEN
rng = np.random.default_rng(0); age = rng.integers(15,19,100); height = rng.normal(170,8,100); weight = rng.normal(60,10,100); y = rng.integers(0,2,100)
Think: Each array is one column → np.column_stack. Shape must be (100, 3), not (3, 100). Splitting = slicing rows, no shuffle needed here.
SOLUTION
X = np.column_stack([age, height, weight])  # (100, 3)

X_train, X_test = X[:80], X[80:]
y_train, y_test = y[:80], y[80:]

X_train.shape, X_test.shape  # (80, 3) (20, 3)

Random — and the seed

rng = np.random.default_rng(42)

rng.random(3)              # uniform
rng.normal(0, 1, size=5)   # N(0, 1)
rng.integers(0, 10, size=5) # ints
rng.choice(["a","b","c"], 2)
  • Seed = reproducibility. Same seed → same numbers.
  • Stage 2 graders rerun your code. Always seed.
  • Old API np.random.seed(42) still works. New default_rng preferred.

Why my score keeps changing

You run your model. Get accuracy 0.84. Run again. Get 0.81. Tweak hyperparameter. Get 0.83. Was the tweak good? You can't tell. Why? Fix it.
Think: Where does randomness enter? Train/test split. Model init. Data shuffling. Without seed, each run = new universe. With seed = same numbers every time.
SOLUTION
SEED = 42
rng = np.random.default_rng(SEED)
data = rng.normal(0, 1, size=100)

# also pass to every sklearn function that takes random_state
train_test_split(X, y, random_state=SEED)
RandomForestClassifier(random_state=SEED)
Critical: Seed everywhere isn't "cheating." It's science. You need controlled experiments to know what changed the score.

Day 1 pitfalls

  • view vs copy — slices are views. Mutating slice mutates original. Use .copy() when scared.
  • int vs float — np.zeros(3) is float. np.zeros(3, dtype=int) if you need int.
  • shape mismatch — (3,) ≠ (3, 1). Broadcasting cares.
  • NaN poisons — np.nan + x = nan. Use np.nanmean, etc.
  • @ vs * — matmul vs element-wise. Different operators.

Most bugs = shape bug. print(a.shape) is your friend.

Day 1 capstone — exam stats

100 students. 5 exams. Score matrix shape (100, 5). Without any for loop, answer: (1) mean per exam, (2) top student's total, (3) how many students passed all 5 (passing = ≥ 50), (4) rank of student #7 by total score.
Plan first: Which axis collapses for "per exam"? For "per student"? How does (scores >= 50).all(axis=1) work? argsort + position lookup for rank.
SOLUTION
rng = np.random.default_rng(42)
scores = rng.integers(30, 100, size=(100, 5))

exam_mean   = scores.mean(axis=0)               # (5,)
top_total   = scores.sum(axis=1).max()           # scalar
all_pass    = (scores >= 50).all(axis=1).sum()    # int

totals      = scores.sum(axis=1)
rank_of_7   = (-totals).argsort().argsort()[7] + 1  # 1-indexed

Day 1 recap

  • Array — fixed-type, n-d grid. Has shape, dtype.
  • Vectorize — drop loops. Operator works element-wise.
  • Broadcast — different shapes auto-stretch (when compatible).
  • Aggregate — sum / mean / max along an axis.
  • Mask — boolean array as index = filter.
  • Combine — column_stack arrays into X, slice rows to split.
