Why arrays?

  • You have 1,000,000 numbers. Multiply each by 2.
  • Python list + for loop $\Rightarrow$ slow. Seconds.
  • NumPy: a * 2. One line. ~50× faster.
  • Same idea powers training neural nets on GPUs.

Loops are expensive. Arrays are cheap. Learn to think in arrays.

What is NumPy?

  • N-dimensional array library for Python.
  • Foundation under pandas, scikit-learn, PyTorch, TensorFlow.
  • Written in C $\Rightarrow$ fast loops without writing C.

Make arrays without typing them

np.zeros(5)              # [0. 0. 0. 0. 0.]
np.ones((2, 3))          # 2x3 ones
np.arange(0, 10, 2)       # [0 2 4 6 8]
np.linspace(0, 1, 5)      # [0. 0.25 0.5 0.75 1.]
np.random.rand(3)        # 3 uniform [0,1)
np.eye(3)                # 3x3 identity
  • zeros / ones — initialize buffers.
  • arange — like range but float-friendly.
  • linspace — N evenly-spaced points. Plotting workhorse.
  • random.rand — quick test data.

Broadcasting

Different shapes — NumPy stretches them to match.

a = np.array([1,2,3])    # (3,)
a + 10                # scalar broadcasts
# [11 12 13]

m = np.ones((3,3))     # (3,3)
m + a                # row broadcasts

Rule: compare shapes from right.
Dim OK if equal, or one is 1.

  • (3,3) + (3,) ✓
  • (3,1) + (1,3) → (3,3) ✓
  • (3,) + (4,) ✗ ValueError

Aggregations & axes

Click an arrow direction to see which cells collapse.

a = np.array([[1,2,3],
              [4,5,6]])

a.sum()              # 21
a.sum(axis=0)        # [5 7 9]  (3,)
a.sum(axis=1)        # [6 15]   (2,)
a.min(axis=1)        # [1 4]    same family

# keepdims=True → keep axis as size 1
a.sum(axis=1, keepdims=True)
# [[6] [15]]  shape (2,1) → broadcasts back
→ pick an axis

axis=0 collapse rows. axis=1 collapse cols. keepdims=True → keep shape for broadcast back (per-row normalize).

More moves you’ll need

Sample: a = [10, 25, 33, 50]. Each tool answers different question.

arg* — “where?” Returns position, not value.

a.argmin()      # 0  (10 at idx 0)
a.argmax()      # 3  (50 at idx 3)
np.argsort(a)   # [0 1 2 3] sort order

where / clip / maximum — reshape values by rule.

np.where(a>20, a, 0)  # [0 25 33 50] keep>20 else 0
np.maximum(a, 30)     # [30 30 33 50] floor at 30
np.clip(a, 20, 40)    # [20 25 33 40] both bounds
np.abs(a - 30)        # [20 5 3 20]   distance

fancy index — pass list of positions, get items in that order.

a[[0, -1]]      # [10 50]   first+last
a[[3, 0, 3]]    # [50 10 50] repeat OK

2D — two lists pair up: (row[i], col[i]).

m = np.arange(9).reshape(3,3)
# [[0 1 2] [3 4 5] [6 7 8]]
m[[2, 0]]   # row 2 then row 0
m[[0,0,-1,-1], [0,-1,0,-1]]
# [0 2 6 8]   four corners

Two patterns cover most exercises: condition → mask → reduce or position → index → value.

Worked: standardize a dataset

Z-score $z = \dfrac{x - \mu}{\sigma}$ — center then scale, so mean=0 std=1. Why? Features like age (0–100) vs salary (0–200k) have different scales — models weight big numbers more. Z-score = same ruler for all.

x = np.array([10,20,30,40,50])

mu    = x.mean()       # 30.0  ← center
sigma = x.std()        # 14.14 ← spread

# step 1: center (subtract mean)
x - mu                 # [-20 -10 0 10 20]

# step 2: scale (divide by std)
z = (x - mu)/sigma     # broadcast both ops
# [-1.41 -0.71 0. 0.71 1.41]

Pitfalls

View vs copy. Slicing returns a view — mutating mutates original. 
b = a[:3]
b[0] = 999      # a changes too!
b = a[:3].copy()  # safe
Shape mismatch. Always check .shape when puzzled. 
a + b   # ValueError if
        # shapes don't broadcast
Integer overflow. np.int8 wraps at 127. 
np.array([200], dtype=np.int8)
# wraps to -56!
# prefer float64 if unsure
axis confusion. Repeat: down=0, across=1. 
m.sum(axis=0)  # down columns
m.sum(axis=1)  # across rows

Why this matters for AI

  • PyTorch tensor = NumPy array + GPU + autograd.
  • TensorFlow tensor = same idea.
  • scikit-learn takes NumPy arrays as input.
  • pandas DataFrame sits on top of NumPy.
  • Images, audio, embeddings, weights — all arrays.

Learn NumPy once. Use it everywhere in AI.

Recap

  • Array — fixed-type, n-dim grid. Has shape, dtype.
  • Vectorize — drop loops. Operator works on every element.
  • Broadcast — different shapes auto-stretch (when compatible).
  • Aggregate — sum / mean / max across an axis.
  • Mask — boolean array as index = filter.
