Why pandas?

  • Every NOAI task ships CSV files. train.csv, test.csv, sample_submission.csv.
  • Python lists $\Rightarrow$ no labels, no types, no joins.
  • NumPy 2D $\Rightarrow$ all numbers only. CSV has strings, dates, NaN.
  • Pandas: labeled tables. Load → explore → clean → train.

What is a DataFrame?

Think Excel sheet. Rows = samples. Columns = features. Each column has a name and a type.

NameAgePclassSurvived
0Braund2230
1Cumings3811
2Heikkinen2631
3Futrelle3511
  • Index — left column. Default 0,1,2,…
  • Columns — top row. Each has a name.
  • dtype per column — Age=int, Name=string. Mixed OK.

Load any CSV

import pandas as pd

df = pd.read_csv('train.csv')
df = pd.read_csv('train.csv', index_col=0)  # use first col as index
  • Convention: always import pandas as pd.
  • Variable named df by tradition. "DataFrame" $\Rightarrow$ df.
  • One line. CSV in memory. Done.

Other readers: pd.read_excel, pd.read_json, pd.read_parquet. Same idea.

Inspect first. Always.

Before touching the data, run these 4. Know what you have.

df.shape         # (891, 12) — rows, columns
df.columns       # Index(['Name','Age','Pclass',...])
df.head(5)       # first 5 rows — eyeball
df.info()        # dtype + non-null count per column
df.describe()    # min/max/mean/std for numeric columns
df.dtypes        # type of each column
  • .info() — fastest way to spot missing values.
  • .describe() — fastest way to spot outliers (huge max, weird min).
  • .head() / .tail() — fastest way to spot encoding issues.

5 minutes inspection saves 5 hours debugging.

Filter rows — boolean mask

Same idea as NumPy. Comparison gives True/False per row. Pass it back to df[...].

df[df['Age'] > 30]                     # adults
df[df['Sex'] == 'female']               # women
df[(df['Pclass'] == 1) & (df['Survived'] == 1)]  # 1st-class survivors
NameAgePclassSurvived
0Braund2230
1Cumings3811
2Heikkinen2631

4Allen3530

Trap: use & and |, NOT and/or. Wrap clauses in parens.

Missing values — NaN

Real CSVs have holes. Pandas marks them NaN. Handle them or models break.

df.isnull().sum()       # count NaN per column
df['Age'].fillna(df['Age'].mean())   # fill with mean
df.dropna()             # drop rows with any NaN
df.dropna(subset=['Age'])    # drop rows where Age is NaN

before

Rule of thumb: mean/median for numeric, mode or "unknown" for strings.

# derive from existing

df['FareLog']    = np.log1p(df['Fare'])

df['Sex'] = df['Sex'].map({'male': 0, 'female': 1})

# count categories
df['Pclass'].value_counts()   # 3: 491, 1: 216, 2: 184
  • Vectorized — applies to every row at once. Same as NumPy.
  • Boolean column ($<$, $>$, $==$) gives True/False $\Rightarrow$ usable as 0/1.
  • .map() — turn strings into numbers. Models eat numbers only.
